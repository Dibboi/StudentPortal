A small-scale **student portal prototype** built for the IMS566 Individual Project.

## ✨ Features
| Requirement | Where |
|---|---|
| Authentication (Login/Register) | index.html + js/auth.js |
| Error feedback | Invalid credentials alert |
| Responsive navigation | Bootstrap navbar on all pages |
| Dashboard with summary + chart | dashboard.html (Chart.js line chart) |
| Data View 1 (Table) | courses.html — course list |
| Data View 2 (Grid) | results.html — result cards + doughnut chart |
| Meaningful data visualisation | GPA trend + grade distribution |
| Professional footer | All pages |
| Mobile-friendly | Bootstrap 5 grid + responsive CSS |

## 🧪 How to Test Login
1. Open index.html.
2. Use the demo account:
   - **Username:** username
   - **Password:** password
3. OR click Register to create a new account.
4. Wrong credentials show a red error message.

## 🛠 Frameworks & Libraries
- Bootstrap 5.3 — layout, components, responsiveness
- Chart.js 4.4 — GPA line chart & grade doughnut chart
- Vanilla JavaScript — authentication, session guard, logout
- Google Chrome — tested browser
